# This system is deliberately over-built

This is a demonstration project, not a system that will take production traffic. Where a real build would minimise moving parts, this one keeps the parts that show something worth understanding — calibrated probabilities, expected-cost decisioning, event-time windows, replayable history. A reader sizing the components against the traffic will conclude they are oversized. They are, on purpose. Judge each component by what it demonstrates, not by whether the load requires it.

The corollary is that the honest scope of any result here is narrow: the plumbing works end to end. Detection quality measured on simulated fraud is not evidence about real fraud.
